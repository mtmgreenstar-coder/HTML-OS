# HTML OS — Android APK

نسخه اندرویدی آفلاین پروژه HTML OS. رابط اصلی از فایل محلی داخل برنامه بارگذاری می‌شود؛ برای اجرای خود رابط به اینترنت نیاز نیست.

## ساخت APK با GitHub Actions
1. تمام محتویات این پوشه را در یک مخزن GitHub آپلود کنید.
2. به زبانه **Actions** بروید.
3. گردش‌کار **Build HTML OS APK** را انتخاب کنید.
4. روی **Run workflow** بزنید (یا یک push به شاخه `main` انجام دهید).
5. پس از پایان موفق، در صفحه اجرای workflow بخش **Artifacts** فایل `HTML-OS-debug-apk` را دانلود کنید.
6. ZIP دانلودشده را باز کنید و `app-debug.apk` را روی گوشی نصب کنید.

## نکات
- نام برنامه: **HTML OS**
- شناسه بسته: `com.htmlos.launcher`
- حداقل اندروید: Android 6.0 (API 23)
- فایل HTML اصلی در `app/src/main/assets/index.html` قرار دارد.
- برای تغییر رابط، همین فایل را جایگزین کنید و دوباره build بگیرید.
- این خروجی debug برای نصب و آزمایش است؛ برای انتشار عمومی در Google Play باید نسخه release امضاشده ساخته شود.
